# QuoteGen Universal V7

Premium enquiry-to-quotation prototype.

## V7 improvements
- Clean, simpler two-column quotation workspace.
- Final quotation is directly editable: customer, company details, validity, item descriptions, specifications, quantities, UOM, prices, payment/delivery details, GST and terms.
- Add required, optional, and service lines directly from the quotation.
- Remove any line directly from the quotation; totals and section totals update immediately.
- Optional items remain excluded from the main required-item total.
- Service lines remain separate from product totals.
- Download/print uses print CSS so only the quotation paper is printed/saved as PDF, not the app UI.
- Raw enquiry parser from V6 retained as the extraction engine.

## Run
Open `index.html` in a modern browser.
